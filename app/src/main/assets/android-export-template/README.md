# {{APP_NAME}} Android application project

This folder is a real Android Gradle project generated by ALVM Studio from a compiled AL program.

## What is included

- `app/src/main/assets/main.room`: the selected AL program compiled to verified ALRM .room v10 bytecode.
- `app/src/main/jniLibs/{{ABI}}/libalvm.so`: ALVM's native Android bridge and bundled Rust CI Runtime for this device ABI.
- `PlayerActivity`: a standalone Android host for the AL program's native UI, buttons, 2D scene, touch areas and frame-loop callbacks.
- `CiRuntimeHost`: the JNI bridge that executes .room bytecode. The original AL source is also included at the project root for reference.

## Build the APK

1. Extract this ZIP.
2. Open the extracted folder in Android Studio.
3. Let Android Studio sync the Gradle project. Use JDK 17 and Android SDK Platform 35.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio writes the debug APK to `app/build/outputs/apk/debug/app-debug.apk`.

The command-line equivalent, when Gradle 8.9 and Android SDK 35 are installed, is:

```bash
gradle --no-daemon :app:assembleDebug
```

## Important limits

- The exported project is restricted to **{{ABI}}** because its native runtime library was copied from the device running ALVM Studio.
- It contains a debug build setup. A release APK for publishing must be signed with your own private release key.
- This exporter currently builds one AL source file into one .room entry module. AL module imports and multi-file linking are not implemented.
- AL APIs that the bundled CI Runtime does not implement will still fail at runtime; packaging does not create missing APIs.
